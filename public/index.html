Getting started

  1. Copy .env.example to .env and set MySQL + JWT_SECRET.
  2. Run mysql -u root -p < db/schema.sql (optional: seed_skills.sql, seed_categories.sql).
  3. Run npm install then npm run dev.
  4. First-time admin: open bootstrap.html (disabled in production unless ALLOW_ADMIN_BOOTSTRAP=true).
  5. Explore open projects or create an account.
